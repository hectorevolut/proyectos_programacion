# 01 — Motor de simulación paralela

> 💤 Proyecto pendiente de diseñar. Se abordará después del Proyecto 2 (pipeline de
> datos), según lo acordado en el plan general (ver [`../README.md`](../README.md)).

Objetivo previsto: partir de una simulación secuencial en C (por ejemplo, autómata
celular tipo Juego de la Vida) e ir paralelizándola progresivamente con **pthreads**,
**OpenMP** y opcionalmente **MPI**, midiendo y visualizando el speedup real desde un
panel web servido por un componente Java.
